# ORLA Digital Studio — Portfolio Website

موقع عربي RTL لاستوديو ORLA Digital Studio، بتصميم متجاوب وتفاعلي وهوية بنفسجية/وردية مستوحاة من ORLA.

## التشغيل

افتحي `index.html` في المتصفح. لتجربة جميع المشاريع بشكل أفضل، استخدمي استضافة GitHub Pages أو خادم محلي:

```bash
python -m http.server 8000
```

ثم افتحي `http://localhost:8000`.

## محتويات المشروع

- `index.html`: الصفحة الرئيسية والخدمات والمعلومات ونموذج الطلب.
- `style.css`: الهوية البصرية والحركات والاستجابة للموبايل.
- `app.js`: معرض المشاريع، الفلاتر، النوافذ التفاعلية، ونموذج الطلب.
- `config.js`: رقم واتساب الاستوديو (غير مضاف حالياً).
- `projects/`: **نسخ كاملة من المواقع التسعة**، بحيث يعمل زر «تجربة الموقع» بدون روابط خارجية أو مستودعات إضافية.

## تفعيل التواصل

افتحي `config.js` وضعي رقم واتسابك بصيغة دولية، بدون علامة + أو مسافات. لا يوجد رقم مفترض أو مزيف. يمكن نسخ رسالة طلب المشروع حتى بدون ضبط واتساب.

## النشر على GitHub Pages

1. أنشئي مستودع GitHub جديداً.
2. ارفعي **جميع محتويات** مجلد `orla-digital-studio` إلى جذر المستودع، بما فيها مجلد `projects`.
3. من Settings → Pages اختاري Deploy from a branch، ثم `main` و`/(root)`.
4. انتظري تفعيل رابط الموقع، ثم اختبري روابط «تجربة الموقع» التسعة.

## قبل إطلاق الموقع تجارياً

- راجعي الصور المستخدمة في المشاريع الفرعية وتراخيص استخدامها؛ بعض الصور تُحمّل من مصادر خارجية.
- استبدلي بيانات المنتجات والعقارات والأطباء والأسعار والمراجعات التجريبية بمحتوى حقيقي قبل تقديم أي نموذج كمشروع عميل.
- لا تعرضي المشاريع التجريبية كأنها أعمال مدفوعة لعملاء حقيقيين.
- ضعي بيانات التواصل الفعلية وسياسة الخصوصية المناسبة إذا أضفتِ تخزيناً أو تحليلات أو جمع بيانات على خادم.
- نموذج التواصل هنا ينشئ رسالة واتساب أو نصاً للنسخ **ولا يحفظ بيانات على خادم**.
