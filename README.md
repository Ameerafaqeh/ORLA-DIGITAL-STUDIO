- الشعار الجديد بدون خلفية: `assets/orla-logo-transparent.png`
- نسخة أفقية للهيدر والفوتر: `assets/orla-logo-header.png`
- إعدادات التواصل: `config.js` (واتساب 972537264996)
- تصميم الموقع الأصلي محفوظ، مع تحسينات العرض على الجوال والوصول والتنقل.

- صور المشاريع الخارجية والخطوط قد تحتاج اتصالاً بالإنترنت.
- لرفع الموقع على GitHub Pages، يجب أن يكون `index.html` في جذر المستودع أو مجلد النشر المختار.
