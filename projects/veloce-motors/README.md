# VÉLOCE Motors — Luxury Car Showroom Demo

موقع عربي RTL تجريبي لمعرض سيارات فاخر، يعمل مباشرة من ملف `index.html` وبدون خادم.

## التشغيل
افتح `index.html` في المتصفح. يمكن رفع الملف إلى جذر مستودع GitHub وتفعيل GitHub Pages من Settings → Pages → Deploy from a branch.

## المزايا
- عرض 8 سيارات ببحث فوري وتصنيفات وفلترة سعر وماركة وترتيب.
- تفاصيل السيارة مع معرض صور تفاعلي.
- حفظ المفضلة في localStorage.
- مقارنة 3 سيارات بجدول مواصفات.
- حاسبة تمويل بقسط شهري تقديري (فائدة سنوية قابلة للتعديل).
- نموذج تجربة قيادة يجهز رسالة واتساب.
- قائمة موبايل وتصميم متجاوب ودعم لوحة المفاتيح وإغلاق النوافذ بـ Escape.

## تفعيل واتساب
داخل `index.html` ابحث عن `const WHATSAPP_NUMBER=''` وضع رقم المعرض بصيغة دولية أرقام فقط، مثل `970599123456` (مثال توضيحي غير حقيقي). قبل ضبط الرقم يتم نسخ رسالة الطلب أو إظهارها للنسخ.

## تعديل السيارات
في `index.html` ابحث عن `const cars=[` وعدّل البيانات التجريبية. أسعار السيارات والمواصفات لا تمثل قوائم بيع حقيقية، والصور التوضيحية قد لا تطابق الموديل المعروض. الصور تُحمّل من Unsplash وتتطلب اتصالاً بالإنترنت. راجع تراخيص الصور واستبدلها بصور مملوكة/مرخصة قبل الاستخدام التجاري.

## تنبيه
لا يوجد Backend، ولا إدارة مخزون، ولا حجز مؤكد، ولا تمويل حقيقي. بيانات المستخدم في نموذج الحجز لا تُرسل لخادم الموقع؛ تُجهز في رسالة واتساب فقط عند إعداد الرقم.
