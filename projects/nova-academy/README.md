# NOVA Academy — Demo Educational Platform

Arabic RTL responsive, static HTML/CSS/JavaScript portfolio concept.

## Run
Open `index.html` in any modern browser, or host the directory on GitHub Pages.

## Features
- Course search and category filtering (6 fictional courses)
- Course detail modal, enrollment and saved courses
- Learner dashboard and lesson completion with localStorage persistence
- Sample quiz with instant feedback
- Demo completion certificate (explicitly non-accredited)
- Responsive navigation, FAQ, mobile layout

## Important
This is a portfolio prototype. Course names, lessons, statistics and certificates are demonstration data. There is no authentication, video learning content, backend, payments, or real credential issuance. Images and Google Fonts load from external providers and need internet access. Replace images with appropriately licensed owned assets before commercial deployment.

## Deployment
Upload `index.html` to the root of a GitHub repository, then Settings → Pages → Deploy from a branch → main / root.
