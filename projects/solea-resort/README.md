# SOLÉA Resort & Villas — Interactive Demo

Arabic RTL responsive resort website built with HTML, CSS and vanilla JavaScript. No build step required.

## Run
Open `index.html` in a browser, or serve the folder with a static HTTP server. To publish to GitHub Pages, upload the contents of this folder to the root of a GitHub repository and enable Pages under Settings > Pages.

## Configure WhatsApp
Edit `config.js` and enter the resort WhatsApp number in international format, digits only (no `+`). Until configured, the booking form copies the request text instead of pretending it sent a booking.

## Included
- 3-image hero slideshow, animated reveal sections, mobile navigation
- Four sample accommodations, category filters and detailed modal views
- Photo gallery lightbox
- Check-in / check-out and guest count selection
- Live pricing calculator with extras and capacity checks
- WhatsApp booking request generator
- Testimonial carousel and FAQs

## Important
This is a fictional demonstration brand. All villas, rates, testimonials, services and photos are placeholders. Photos are remotely loaded from Unsplash and require internet access; verify image licensing and replace them with property-owned images before production. There is no backend, real availability inventory, confirmed booking, online payment or guest data storage. Do not present sample testimonials as genuine reviews.
