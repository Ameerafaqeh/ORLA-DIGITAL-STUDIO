# Maison Sucré — متجر حلويات تجريبي

موقع عربي RTL، متجاوب، يعمل كملفات ثابتة على GitHub Pages.

## التجربة
افتحي `index.html` في المتصفح (يتطلب اتصال إنترنت لتحميل الخطوط والصور).

## تفعيل الطلبات
افتحي `config.js` وأضيفي رقم واتساب المحل بصيغة دولية **بدون +** في `whatsappNumber`، وعدّلي رابط إنستغرام. لا يُرسل الطلب تلقائياً؛ يفتح واتساب برسالة جاهزة وعلى العميل إرسالها.

## تعديل المنتجات والأسعار
من مصفوفة `products` في `script.js`. الأسعار بالشيكل، وهي أمثلة فقط. أسعار الكيك المخصص في `sizePrices` و`flavorPrices`.

## النشر المجاني
1. أنشئي مستودع GitHub جديداً.
2. ارفعي الملفات الأربعة في جذر المستودع: `index.html`, `style.css`, `script.js`, `config.js`.
3. Settings > Pages > Deploy from a branch > main > /(root).
4. انتظري ظهور رابط GitHub Pages.

## مهم
- الصور مستضافة من Unsplash ويجب مراجعة ملاءمتها وترخيصها واستبدالها بصور المنتجات الحقيقية قبل الاستخدام التجاري.
- الموقع نموذج عرض؛ لا يوجد دفع إلكتروني، ولا لوحة تحكم، ولا حفظ طلبات، ولا تحقق من المخزون، ولا تحميل صورة مرجعية.
- السلة محفوظة في ذاكرة الصفحة فقط وتُصفّر عند إعادة تحميلها.
- لحفظ الطلبات وإدارة المخزون والمواعيد أو رفع الصور تحتاجين Backend وتخزيناً آمناً.
- لا تضعي كلمات مرور أو مفاتيح API سرية في ملفات الموقع الثابتة.
