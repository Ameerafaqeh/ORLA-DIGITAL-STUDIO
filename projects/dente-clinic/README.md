# DENTÉ Clinic — Dental & Aesthetic Clinic

نموذج موقع عربي RTL متجاوب لعيادة أسنان وتجميل، بتصميم Editorial Sage / Ivory.

## التشغيل

افتح `index.html` مباشرة في المتصفح. لا يحتاج npm أو خادم أو قاعدة بيانات.

## إعدادات العميل

في `config.js` عدلي `clinicName` و`whatsappNumber` (أرقام دولية بدون +) و`instagramUrl` و`mapsUrl`.

في `index.html` استبدلي اسم العيادة، نصوص الخدمات، أوقات العمل، أسماء الأطباء، الصور، وبيانات الاتصال. **الأطباء والأسماء والخدمات والصور توضيحية فقط**، وليست شهادات أو أعمالاً حقيقية. لا تنشريها باعتبارها معلومات عيادة فعلية.

## الوظائف المتاحة

- تنقل متجاوب وقائمة موبايل
- صفحة خدمات وصور مع أزرار تنقل إلى نموذج الحجز وتحدد الخدمة
- نموذج موعد يتحقق من الحقول والتاريخ ويرسل رسالة واتساب معدّة مسبقاً
- معرض صور مع تكبير
- أسئلة شائعة تفاعلية
- مؤشر تقدم التمرير
- تصميم متجاوب ودعم الحركة المخفضة

## حدود النسخة الثابتة

نموذج واتساب **طلب موعد** فقط، لا يحجز وقتاً في تقويم ولا يمنع تضارب المواعيد ولا يحفظ بيانات في خادم. يحتاج نظام إدارة الحجوزات، حسابات الأطباء، إشعارات تلقائية، لوحة تحكم، وتخزين بيانات المرضى إلى Backend وقاعدة بيانات مع ضوابط أمن وخصوصية ملائمة. تجنبي جمع بيانات صحية حساسة عبر واتساب في هذه النسخة.

الصور محملة من Unsplash عبر الإنترنت، والخطوط من Google Fonts. قد تحتاج صوراً محلية مرخصة للاستخدام التجاري والتأكد من ملاءمة تراخيص الصور عند إطلاق موقع لعميل.

## نشر مجاني على GitHub Pages

1. أنشئي مستودع GitHub جديداً.
2. ارفعي ملفات المجلد في جذر المستودع (وليس المجلد الخارجي نفسه).
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. انتظري ظهور رابط الموقع. لا توجد حاجة لخادم مدفوع.

## تنبيه

هذا مشروع Portfolio تجريبي، وليس موقع عيادة حقيقية أو مصدراً لنصيحة طبية.
