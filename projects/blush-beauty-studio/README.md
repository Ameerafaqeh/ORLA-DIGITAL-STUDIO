# Blush Beauty Studio — نموذج موقع صالون

موقع عربي متجاوب يعمل باستخدام HTML/CSS/JavaScript فقط، قابل للنشر مجاناً على GitHub Pages.

## تجربة الموقع
افتحي `index.html` في المتصفح. الصور والخطوط تُحمّل من الإنترنت.

## تفعيل طلب الحجز عبر واتساب
افتحي `config.js` وعدّلي:
- `whatsappNumber`: رقم واتساب الصالون بصيغة دولية **بدون + أو مسافات** (مثال توضيحي: `970599123456`). تركه فارغاً يعرض تنبيهاً بدلاً من إرسال طلب إلى رقم غير معروف.
- `instagramUrl`: رابط إنستغرام الحقيقي.
- `mapsUrl`: رابط موقع الصالون الحقيقي.
- `salonName`: اسم الصالون الذي يظهر في رسالة الحجز.

الحجز عبارة عن **طلب عبر واتساب** وليس حجزاً مؤكداً؛ لا تُخزَّن المواعيد ولا تُفحص التوافرات. عند الضغط على الإرسال، يفتح واتساب برسالة جاهزة، وتحتاج الزبونة لإرسالها بنفسها.

## نشر مجاني على GitHub Pages
1. أنشئي Repository جديداً على GitHub باسم `blush-beauty-studio`.
2. ارفعي الملفات `index.html`, `style.css`, `script.js`, `config.js` إلى **جذر** المستودع (لا ترفعي مجلداً يحوي الملفات دون استخراجها).
3. افتحي Settings → Pages → Build and deployment → Deploy from a branch.
4. اختاري `main` و`/(root)` واضغطي Save.
5. بعد النشر، يكون الرابط بالشكل `https://USERNAME.github.io/blush-beauty-studio/`.

## قبل عرض الموقع كعمل لعميل
- الصور الخارجية المستخدمة صور توضيحية وليست أعمالاً حقيقية للصالون. راجعي تراخيص الاستخدام قبل تسليم موقع تجاري، ويفضل استبدالها بصور يملكها العميل أو صور مرخّصة له.
- أسماء أعضاء الفريق افتراضية، وكذلك العروض والنصوص. استبدليها بالمعلومات الصحيحة.
- حددي ساعات العمل الفعلية وعدّلي أوقات نموذج الحجز وفقاً لها.
- تأكدي من موافقة العميل على نشر بياناته وصوره.

## ما الذي يحتاج Backend؟
**لا يحتاج Backend:** عرض الخدمات، المعرض والفلاتر، الأسئلة الشائعة، فتح طلب الحجز في واتساب، والتواصل.

**يحتاج Backend أو خدمة خارجية:** حفظ الحجوزات، منع تعارض المواعيد، لوحة تحكم، تسجيل دخول للموظفات، إشعارات تلقائية، إدارة مخزون أو مدفوعات، والتكامل الآلي مع WhatsApp Business API.

## هيكل المشروع
- `index.html`: المحتوى والهيكل
- `style.css`: التصميم والاستجابة للموبايل
- `script.js`: القائمة، الفلاتر، والتحقق من نموذج الحجز
- `config.js`: بيانات الصالون

## النسخة التحريرية (Editorial Edition)
- تصميم مُحدّث بألوان كريمية ووردية مطفأة، وتوزيع صور أكثر تنوعاً.
- ملف `editorial.css` يحتوي على تحسينات التصميم ويُحمّل بعد `style.css`.
- تفاعلات جديدة: تكبير صور المعرض بالضغط، دعم لوحة المفاتيح، ظهور تدريجي هادئ، وشريط تقدم التصفح.
- الموقع تجريبي؛ الصور والأسماء ليست أعمالاً حقيقية. استبدليها بمحتوى مرخّص من الصالون قبل استخدامه تجارياً.
- يحتاج الإنترنت لعرض الصور الخارجية وخطوط Google. يمكن استبدال الصور بملفات محلية لاحقاً.
