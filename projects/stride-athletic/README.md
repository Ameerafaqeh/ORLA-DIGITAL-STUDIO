# STRIDE Athletic Club — Demo Website

موقع عربي متجاوب لنادي رياضي، نموذج Portfolio تجريبي.

## التشغيل
افتحي `index.html` مباشرة في المتصفح. يلزم اتصال إنترنت لتحميل صور Unsplash والخطوط من Google Fonts.

## تخصيص الموقع
- في `config.js`: أضيفي رقم واتساب بصيغة دولية بدون +، وروابط إنستغرام والخرائط.
- في `index.html`: عدّلي الأسعار والاشتراكات والبرامج وجدول الحصص (مصفوفة `classes`)، وصور الفريق والنصوص.
- الأسعار والأسماء والحصص والخصومات تجريبية، والصور صور مرجعية خارجية وليست للنادي الفعلي. تحققي من ترخيص الصور قبل استخدام الموقع تجارياً.

## النشر على GitHub Pages
1. أنشئي Repository جديداً.
2. ارفعي `index.html` و`config.js` إلى جذر المستودع.
3. Settings → Pages → Deploy from a branch → main / (root).
4. انتظري رابط الموقع المجاني.

## ما يعمل بدون Backend
- تصميم متجاوب، قائمة هاتف، عرض البرامج، تصفية جدول الحصص، حاسبة الاشتراك، نموذج يفتح واتساب برسالة مُعدّة.

## ما يحتاج Backend
- حجز حقيقي مع تقويم وتأكيد آلي ومنع التعارض.
- إدارة العضويات والدفع والفواتير.
- لوحة إدارة للمدربين والحصص والاشتراكات.
- حسابات مستخدمين وحفظ بياناتهم بشكل آمن.

ملاحظة: النموذج لا يخزن بيانات الزبائن ولا يرسلها إلى خادم. لا تستخدمي أرقام واتساب أو عناوين حقيقية غير مصرّح بها.
