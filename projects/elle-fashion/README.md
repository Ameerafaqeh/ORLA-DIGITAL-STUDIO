# ÉLLE Fashion — نموذج متجر أزياء نسائية

موقع تجريبي عربي RTL، قابل للنشر مجاناً على GitHub Pages، باستخدام HTML وCSS وJavaScript فقط.

## التشغيل
افتحي `index.html` في المتصفح. الصور والخطوط تحتاج اتصال إنترنت.

## التخصيص
افتحي `config.js` وأضيفي رقم واتساب المتجر بصيغة دولية دون علامة +، ورابط إنستغرام والبريد الإلكتروني.
المنتجات والأسعار والصور التجريبية موجودة في مصفوفة `products` في `app.js`. استبدليها ببيانات حقيقية وصور مرخّصة للعميل قبل الاستخدام التجاري.

## المميزات
- تصنيفات، بحث مباشر، ترتيب، فلترة سعر ومقاس
- نافذة تفاصيل المنتج مع اختيار المقاس واللون
- سلة ومفضلة محفوظتان محلياً في متصفح المستخدم عبر localStorage
- نموذج طلب يجمع بيانات الزبونة وينشئ رسالة واتساب جاهزة؛ لا يُرسل الطلب تلقائياً
- متجاوب مع الهواتف والحواسيب

## النشر المجاني
ارفعي محتويات المجلد (وليس المجلد نفسه) إلى مستودع GitHub عام، ثم Settings → Pages → Deploy from a branch → main / (root). سيظهر رابط الموقع بعد النشر.

## حدود النسخة التجريبية
لا يوجد Backend أو قاعدة بيانات أو دفع إلكتروني أو لوحة تحكم أو متابعة مخزون أو احتساب توصيل أو حماية من الطلبات المتزامنة. الأسعار والمنتجات والمحتوى وهمية لغرض العرض، والصور مأخوذة من روابط Unsplash الخارجية وقد لا تطابق المنتجات بدقة. تأكدي من حقوق استخدام الصور عند تسليم موقع تجاري.
لا تستخدمي هذا النموذج لجمع بيانات دفع حساسة. لا يتم حفظ بيانات نموذج الطلب على خادم؛ تفاصيله تذهب إلى واتساب فقط عندما يضغط الزبون على إرسال الرسالة.
